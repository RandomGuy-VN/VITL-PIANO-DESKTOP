— Native Performance

Engineered for absolute precision

Built completely in Rust & C++ for zero latency, kernel input simulation, and pure standalone reliability.

Kernel /dev/uinput Macro

Hardware-level USB virtual keyboard creates real physical key events at the kernel level. Fully bypasses Wayland and X11 compositor isolation in Roblox.

Built-in Audio Synthesizer

High-fidelity polyphonic synth with configurable volume, reverb mix, ADSR envelopes, and velocity scaling for practicing without game audio.

nanoMIDI Hub (480+ Songs)

Direct integration with nanoMIDI API. Search, stream, and save hundreds of virtual piano sheets directly to your local library in one click.

Global evdev Hotkeys

Kernel-level physical keyboard listeners capture hotkeys (F1–F5, Space, Esc, Speed, Transpose) regardless of window focus.

100% External & Safe

Zero injection into Roblox, no memory modifications, no Lua executors required. Operates as a completely external native app.

Humanizer Engine

Configurable micro-timing jitter, chord arpeggiation delay, and transposition offsets for expressive and natural performances.
