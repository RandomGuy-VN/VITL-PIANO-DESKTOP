Engineered for absolute precision

Crafted completely in Rust & C++ for mathematical timing, drift-free hardware clocks, and standalone reliability.

Kernel /dev/uinput Input Macro

Hardware-level Linux kernel virtual keyboard generates genuine input events with 61-key folding & 88-key extended mode, bypassing all compositor isolation.

Physical Modeling & SoundFont Synth

Dual-engine audio synthesizer: physical string vibration modeling with damper releases, or custom SoundFont (.sf2) sample soundscapes with real-time reverb.

MuseScore Direct URL Importer

Paste any MuseScore score link. The JMuse auth engine automatically resolves and fetches the multi-track MIDI file directly into your library.

Dynamic BPM & Tap Tempo

Monotonic hardware clock tracking follows complex score tempo maps (accelerandos, ritardandos, rubatos) and features an interactive Tap Tempo calculator.

Dynamic Velocity & Human Touch

Dynamic velocity sensitivity curves, fixed uniform levels, human flam delays, and key slip simulation for natural, expressive performances.

Global evdev Hotkeys

Global hardware key interceptors (F1–F5, Space sustain, speed modifiers) give you seamless control while playing full-screen inside Roblox.
